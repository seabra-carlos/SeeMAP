# Primeira entrega técnica — fundação SeeMAP 2.0

Inclui:
- Estrutura inicial de integração do cliente Supabase (`src/lib/supabase.ts`).
- Modelo SQL inicial com perfis, estabelecimentos, sensores, chamados e eventos.
- RLS habilitado nas tabelas e políticas iniciais restritivas.
- Exemplo de variáveis de ambiente sem segredos.
- Decisões arquiteturais e itens obrigatórios antes de produção.

Ainda não inclui:
- Projeto Supabase criado/configurado em nome do usuário.
- Chaves Google Maps ou integração ativa.
- Login real conectado às telas existentes.
- API VRBus (não há autorização/documentação disponível).
- Firmware ESP32, MQTT ou notificações reais.
- Validação de navegação acessível em campo.

Esta entrega é uma base de desenvolvimento, não um aplicativo pronto para uso em deslocamentos reais.


A migração 001 original foi removida nesta entrega por incompatibilidade com o banco existente. Consulte README.md para as instruções atuais.
